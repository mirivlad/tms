# Восстановление доступа

TMS не требует внешних сервисов для аварийного восстановления аккаунта.

## Через браузер

Форма `/forgot-password` принимает имя пользователя или email и всегда возвращает одинаковый внешний ответ. Если настроен SMTP, TMS отправит одночасовую reset-ссылку по email. Если к аккаунту привязан Telegram и бот настроен, ссылка также может быть отправлена туда.

Raw verifier reset-токена в БД не хранится — сохраняется только SHA-256 hash.

## Локальное восстановление self-hosted установки

Когда email и Telegram недоступны, используйте консоль контейнера `app`.

Создать одноразовую ссылку без немедленной смены пароля:

```sh
php bin/issue-password-reset.php admin
```

Сменить пароль напрямую:

```sh
php bin/reset-password.php admin
```

Интерактивный ввод предпочтителен: пароль не остаётся в history shell. Для автоматизации переменная `TMS_RESET_PASSWORD` может быть передана только конкретному процессу.

Успешная смена пароля отзывает постоянные login-токены и незавершённые reset-токены аккаунта.

Если пользователей в БД ещё нет, создайте первого администратора через `bin/create-admin.php`.
